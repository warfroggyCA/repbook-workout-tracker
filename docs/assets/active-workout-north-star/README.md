# Active Workout North Star artboards

These seven static artboards are the durable visual reference for
[`ACTIVE_WORKOUT_NORTH_STAR.md`](../../ACTIVE_WORKOUT_NORTH_STAR.md). They were
supplied and approved for Repbook project documentation and contain synthetic
workout content only.

The images preserve the design direction even if the original hosted artifact
is unavailable. They are documentation assets, not runtime application assets
or proof that the states are implemented.

The written North Star is authoritative when visible mockup wording conflicts
with the approved interaction, data, recovery, or accessibility contract. In
particular, the equipment-conflict artboard's `Log it anyway` action is not an
approved product action.
