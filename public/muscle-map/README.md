# Froggy muscle map artwork

Approved AI-generated Froggy mannequin concept sheet, without shorts, used with schematic SVG muscle overlays. This is original project concept artwork, not the clothed Snow-based exercise-demonstration rig. It contains no Program or personal data. Front/back crop coordinates and overlays are owned by `src/lib/froggy-muscle-regions.json`. No anatomical certification is implied.

Both the full map and compact summaries use the same image through native SVG silhouette clips in
`src/lib/froggy-muscle-silhouettes.json`. The clips remove the surrounding
background while retaining the original pixel coordinates and the released
muscle overlays. The source figure image stays unchanged. Compact summaries retain transparent
backgrounds; the full map places the same outline over a decorative gym backdrop.

The full map adds a soft, decorative SVG contact shadow beneath the feet,
behind the clipped figure. Compact summaries keep their fully transparent
presentation. The shadow carries no muscle or set information.

Front/back view names are accessible SVG labels, without visible captions.

## Gym backdrop

`gym-bokeh-v1.webp` is an original background generated with the built-in image
generation tool on 2026-09-12. It contains no people, branding or user data. The
1536 × 1024 WebP is about 60 KB. CSS adds a neutral veil and separate lightly backed
status/legend text for readability. It is a CSS background, not an interactive
overlay; figure selection and the decorative foot shadows remain separate.

Generation prompt:

> Use case: photorealistic-natural. Asset type: decorative background for a fitness app muscle-map panel. Create a softly defocused empty modern gym interior, photographic optical bokeh, neutral light grey tones, restrained warm daylight, subtle distant weight racks and gym equipment at the sides. Landscape composition, broad calm uncluttered centre for two full-body character cutouts to be composited by the app. Soft grey floor visible in the bottom quarter for contact shadows. Strong depth of field blur throughout equipment, very low contrast, airy but not washed-out white. No people, no character, no text, no signage, no logo, no watermark. This is only the background, not a UI mockup.
