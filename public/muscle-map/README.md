# Froggy muscle map artwork

Approved AI-generated Froggy mannequin concept sheet, without shorts, used with schematic SVG muscle overlays. This is original project concept artwork, not the clothed Snow-based exercise-demonstration rig. It contains no Program or personal data. Front/back crop coordinates and overlays are owned by `src/lib/froggy-muscle-regions.json`. No anatomical certification is implied.

Compact summaries use the same image through native SVG silhouette clips in
`src/lib/froggy-muscle-silhouettes.json`. The clips remove the surrounding
background while retaining the original pixel coordinates and the released
muscle overlays. No extra raster download, third-party asset, or image-generation
service is required. The full map's original image and crop are unchanged.
